Boxes.js Documentation

Boxes.js designs laser-cut wooden boxes with dividers: free per-zone dimensions, adjustable wall and divider heights, finger joints, holes, an optional fixed lid, and an optional sliding drawer.

Everything runs locally in your browser — there is no server and no account. Your projects are saved automatically to this browser, and you can export a project as JSON to back it up or move it elsewhere. When you're ready to cut, export multi-page SVG files sized to your laser bed.
