Managing Projects

My projects is the app's home screen, and where every box you design lives.

The project list

From here you can create a new project, open an existing one, or delete one you no longer need. Each row also offers its own JSON export/import, for moving a single project between browsers or machines — separate from the in-editor Export (JSON) button described in Export & Cutting.

The list also links to My machine and Preferences, where your defaults for new projects live.

Autosave

While a project is open, changes are saved automatically after a short pause in editing — the delay is configurable in Preferences. Autosave also flushes immediately when you close the tab or navigate away from the editor, so you shouldn't lose work in progress.

Opening the app fresh, with no specific screen bookmarked, resumes whichever project you last had open.
