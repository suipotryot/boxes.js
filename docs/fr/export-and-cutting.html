Export & découpe

Deux boutons dans la barre d'outils, deux fichiers très différents.

Exporter (SVG) — le fichier de découpe

Produit les fichiers réellement envoyés au laser. Les pièces sont d'abord groupées par épaisseur de matériau, puis pagées selon votre zone de découpe (voir Machine & préférences), en conservant l'espacement configuré aussi bien entre les pièces que le long des bords de page.

Chaque groupe d'épaisseur se télécharge en un ou plusieurs fichiers SVG, un par page, nommés d'après le projet et le numéro de page. Comme les navigateurs bloquent les téléchargements multiples trop rapides, les fichiers se téléchargent à environ 300 ms d'intervalle — une petite pause est normale pour des boîtes avec plusieurs groupes d'épaisseur ou plusieurs pages.

Activez Étiqueter les pièces (dans la section Options du panneau de gauche) pour graver le nom de chaque pièce sur son propre contour, dans l'aperçu à l'écran comme dans le SVG exporté — pratique pour distinguer des pièces qui se ressemblent une fois découpées.

Empaquetage et imbrication

Les pièces sont empaquetées avec un algorithme d'empaquetage rectangulaire (MaxRects) qui remplit efficacement l'espace restant — mais ça reste un empaquetage par boîte englobante : une pièce irrégulière (par exemple avec une encoche courbe) réserve quand même toute son emprise rectangulaire, marge vide comprise. Ce n'est pas une véritable imbrication de polygones.

Astuce

Pour une disposition plus dense avec une véritable imbrication des formes irrégulières, importez le SVG exporté dans l'outil gratuit Deepnest. Boxes.js affiche un résumé du nombre de pages et cette même astuce, juste au-dessus du bouton d'export.

Une pièce surdimensionnée — plus grande que la zone de découpe elle-même — n'est jamais silencieusement écartée : elle est placée seule sur sa propre page.

Exporter (JSON) — le fichier projet

Enregistre l'état complet du projet (dimensions, grille, trous, encoches, réglages du couvercle/tiroir, etc.) dans un fichier JSON. C'est pour sauvegarder ou réimporter un projet — pas un fichier de découpe. Quand le navigateur le permet, ça ouvre une vraie boîte de dialogue d'enregistrement (l'API File System Access) ; sinon, ça se rabat sur un téléchargement classique vers le dossier de téléchargements par défaut du navigateur.

Voir Gestion des projets pour l'import/export propre à la liste des projets, distinct du bouton JSON dans l'éditeur.
