Getting Started

Build your first box in a few minutes.

1. Create a project

Open the app — you land on My projects. Click the button to create a new project. A new project starts from your Preferences and machine defaults, so it's worth setting those once before your first box.

2. Set the grid

In the editor's left panel, set Columns and Rows as comma-separated lists of sizes in millimeters, for example 100, 80, 100 for three columns of those widths. Each value becomes one column or row of the grid — see The Grid Model for how this maps to walls and dividers.

3. Set thickness and height

Still in the left panel, open Thickness & heights and set the outer wall thickness, the inner divider thickness, the outer wall height, and the default divider height. These apply everywhere unless you override a specific wall — see Walls & Joints.

4. Inspect and adjust a wall

Click any wall line in the grid drawing to select it. The right panel (the inspector) shows that wall's state — present or absent, its height — and, once a piece is selected, its holes and finger-pull notches. Removing an inner divider or overriding one wall's height is done here.

5. Check the pieces

Below the grid, the preview strip lists every piece the app has computed from your settings — every wall, divider, and the base plate — as a small standalone drawing. Click a card to select that piece in the inspector.

6. Export for cutting

When the box looks right, use the toolbar's Export (SVG) button to download laser-ready cutting files, paginated to your laser bed size. See Export & Cutting for what gets exported and how pages are laid out.

Tip

Your project is saved automatically as you work — there's no save button. Use Export (JSON) if you want a backup file or want to move the project to another browser or machine.
