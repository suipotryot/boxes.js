FAQ

Can I undo a change?

Ctrl+Z undoes, Ctrl+Shift+Z redoes, while the editor is focused.

Why isn't the exported layout as tight as I expected?

Boxes.js packs pieces by their rectangular bounding box, not their exact outline — see Export & Cutting. For real irregular-shape nesting, run the exported SVG through Deepnest.

Is my data stored online anywhere?

No — everything runs locally in your browser, and projects are stored there. Use Export (JSON) (see Export & Cutting) if you want a portable backup, since browser storage can be cleared or is specific to one browser/device.

What file formats can I export?

SVG for cutting, and JSON for saving/reloading a project. There is no DXF export today.

I changed My machine or Preferences, but an existing project didn't change.

That's expected — those two screens only set defaults for new projects. See Machine & Preferences.
