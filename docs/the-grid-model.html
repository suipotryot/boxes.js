The Grid Model

Boxes.js builds a box from a grid of cells, not a fixed set of box "shapes".

Columns and rows

The grid is defined by two comma-separated lists: Columns (widths, left to right) and Rows (depths, front to back). Each entry is one column or row width in millimeters — they don't need to be equal, so 60, 120, 60 gives you a wide center compartment flanked by two narrower ones.

The number of entries sets the number of cells; the grid lines between and around them become walls and dividers.

Segments

Every wall line in the grid drawing is a segment — one edge between two grid intersections. Click a segment to select it in the inspector, which shows:

  • Present / absent — an inner segment (a divider) can be removed to merge two cells into one compartment. Outer perimeter segments can't be removed.
  • Height — overridable per segment. Changing the height of an outer segment applies to the whole outer perimeter, since the lid needs a flat, level rim to sit on.

Pieces

Several segments in a straight line, all present, are grouped into a single piece — the actual part that gets cut, with its own finger joints along shared edges. That's what's shown in the preview strip and what the inspector's holes/notches sections apply to once you select one.

Outer walls vs. inner dividers

The grid distinguishes two kinds of walls, each with its own thickness setting (see Walls & Joints):

KindWhereCan be removed?
OuterThe box's perimeterNo
InnerDividers between cellsYes

Warning

Resizing the grid (changing the Columns or Rows list) can discard segment and floor customizations that no longer map onto the new layout. The app asks for confirmation before applying a resize that would lose work.
