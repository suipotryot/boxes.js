Export & Cutting

Two toolbar buttons, two very different files.

Export (SVG) — the cutting file

Produces the files you actually send to the laser. Pieces are first grouped by material thickness, then packed onto pages sized to your laser bed (see Machine & Preferences), with the configured spacing kept both between pieces and along the page edges.

Each thickness group downloads as one or more SVG files, one per page, named after the project and page number. Because browsers block rapid multi-file downloads, files download roughly 300 ms apart — expect a short pause between them for boxes with several thickness groups or pages.

Turn on Label pieces (in the left panel's Options section) to engrave each piece's name into its own outline in both the on-screen preview and the exported SVG — handy for telling similar-looking pieces apart once they're cut.

Packing and nesting

Pieces are packed with a rectangular bin-packing algorithm (MaxRects) that fills leftover space efficiently — but it's still bounding-box packing: an irregular piece (say, one with a curved notch) still reserves its full rectangular footprint, empty margin included. It isn't true polygon nesting.

Tip

For denser layouts with real irregular-shape nesting, import the exported SVG into the free tool Deepnest. Boxes.js shows a page-count summary and this same tip directly above the export button.

An oversized piece — bigger than the laser bed itself — is never silently dropped: it's placed alone on its own page instead.

Export (JSON) — the project file

Saves the whole project's state (dimensions, grid, holes, notches, lid/drawer settings, and so on) to a JSON file. This is for backing up or re-importing a project — it is not a cutting file. Where your browser supports it, this opens a real save-location dialog (the File System Access API); otherwise it falls back to a normal download into your browser's default downloads folder.

See Managing Projects for the project list's own, separate import/export of saved projects.
