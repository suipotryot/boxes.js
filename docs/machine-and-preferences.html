Machine & Preferences

Two screens, reachable from My projects, that hold your personal defaults.

Note

Both screens only set the defaults used when creating a new project. Changing them never modifies a project that already exists — open that project and adjust its own settings instead.

My machine

Your laser cutter's defaults:

  • Laser bed width / height — the cuttable area, used to lay out export pages.
  • Spacing — the minimum gap left between neighboring pieces on the same export page.
  • Burn (kerf) — your laser's kerf compensation, described in Walls & Joints.

Preferences

  • Finger joint defaults — finger width, space width, minimum margin, and play, described in Walls & Joints.
  • Autosave delay — how long the editor waits, after you stop making changes, before saving the open project (see Managing Projects).
